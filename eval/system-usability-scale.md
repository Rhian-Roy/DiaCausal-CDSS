# System Usability Scale (SUS) — DiaCausal

Give this to each clinician **after** their session. It takes two minutes.

The SUS is the standard 10-question usability questionnaire (Brooke J. *SUS: a quick and
dirty usability scale.* In: Usability Evaluation in Industry, 1996). Keep the wording
exactly as it is — changing it makes the score incomparable with everyone else's.

Clinician (initials or study ID): ______   Date: ______   Session length: ____ minutes

For each statement, circle one: **1 = strongly disagree … 5 = strongly agree**

| # | Statement | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 1 | I think that I would like to use this system frequently | ☐ | ☐ | ☐ | ☐ | ☐ |
| 2 | I found the system unnecessarily complex | ☐ | ☐ | ☐ | ☐ | ☐ |
| 3 | I thought the system was easy to use | ☐ | ☐ | ☐ | ☐ | ☐ |
| 4 | I think that I would need the support of a technical person to be able to use this system | ☐ | ☐ | ☐ | ☐ | ☐ |
| 5 | I found the various functions in this system were well integrated | ☐ | ☐ | ☐ | ☐ | ☐ |
| 6 | I thought there was too much inconsistency in this system | ☐ | ☐ | ☐ | ☐ | ☐ |
| 7 | I would imagine that most people would learn to use this system very quickly | ☐ | ☐ | ☐ | ☐ | ☐ |
| 8 | I found the system very cumbersome to use | ☐ | ☐ | ☐ | ☐ | ☐ |
| 9 | I felt very confident using the system | ☐ | ☐ | ☐ | ☐ | ☐ |
| 10 | I needed to learn a lot of things before I could get going with this system | ☐ | ☐ | ☐ | ☐ | ☐ |

## Working out the score

1. Odd-numbered questions: subtract 1 from the answer (1→0 … 5→4).
2. Even-numbered questions: subtract the answer from 5 (1→4 … 5→0).
3. Add the ten numbers and multiply by 2.5. The result is between 0 and 100.

It is **not** a percentage. As a rough guide, 68 is average; above 80 is good. Report the
mean and the range across clinicians, and say how many people were asked — with a handful
of clinicians the number is indicative, not a measurement.
