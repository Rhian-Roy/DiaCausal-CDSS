Scene 04

Patients with a known truth

5,000 synthetic, India-calibrated patients. We planted the true effects, so we can grade every method.

SGLT2iDPP-4iSUx: HbA1c 7–13% · y: eGFR 30–120 · illustration, 1,200 patients
  1. Details: age, sex, HbA1c, eGFR, BMI, history
  2. A “doctor” model picks the drug: confounding built in
  3. Each drug's true effect is planted
  4. Outcome = drift + regression to the mean + effect + noise
  5. Truth hidden: methods see only what a hospital sees

R09 eGFR < 60: low-sugar risk (cut-off team-set). Source: glimepiride label

Rules live only in data/rules.csv; a test fails if a threshold is typed into the code. An excluded option is never estimated.

Scene 06

Propensity and overlap

If almost no similar patient got a drug, a fair comparison is impossible, so we say so.

Propensity = the chance that a patient like this got each drug. Multinomial logistic regression, cross-fitted over 5 folds. Below 0.05 → “insufficient evidence”.

Scene 07

Removing the bias

Three causal methods land on the planted truth; the naive average does not.

SGLT2i minus DPP-4i · mean estimate and typical 95% interval over 20 synthetic cohorts of 5,000

IPW

Weight each patient by 1 ÷ their chance of the drug they got

MATCHING

Pair similar patients who got different drugs

AIPW · DOUBLY ROBUST

Outcome model + weighted correction: right if either model is right

Balance: the largest standardised difference between groups falls from 0.70 to 0.08 after weighting (target < 0.1).
